前端核心功能要求

一、故障树可视化编辑

1. 图形化展示与编辑界面
   - 支持以树状图/逻辑图形式清晰呈现"顶事件—中间事件—底事件"层级结构
   - 提供交互式节点操作：拖拽、缩放、展开/折叠
   - 支持节点增删、逻辑门（AND/OR等）类型切换
   - 节点需标注事件名称、类型（顶/中/底）、来源依据
   - 图形布局应自动优化，避免重叠，确保可读性

2. 路由配置
   - 故障树列表页: /fault-tree
   - 创建新故障树: /fault-tree/edit/new
   - 编辑现有故障树: /fault-tree/edit/:id

二、AI生成结果与专家修正协同

1. AI生成结果展示
   - 初始故障树由后端AI生成后，前端需完整渲染
   - 高亮显示AI置信度较低或待确认的节点

2. 专家修正功能
   - 专家修改时（调整连接关系、修正逻辑门），界面需实时响应
   - 支持撤销/重做操作
   - 修改操作需触发后端逻辑校验请求
   - 在界面上直观展示AI返回的逻辑冲突提示（如循环依赖、冗余路径等）及优化建议

三、知识溯源与透明性

1. 节点溯源信息
   - 每个事件节点支持点击查看其AI提取的原始依据（如手册段落、维修记录片段）
   - 以侧边栏、悬浮窗或弹窗形式展示结构化溯源信息

2. 可解释性展示
   - 确保每个故障树节点都有明确的来源说明

四、多源数据输入

1. 文件上传
   - 支持文件格式: PDF, TXT, DOCX
   - 提供文件上传区域，支持预览
   - 允许用户指定顶事件及生成偏好

2. 参数配置
   - 设备类型(equipmentType)选择或手动输入，默认为"通用型"
   - 来源类型(sourceType)设置
   - 是否持久化到知识库(persistToKnowledgeBase)

五、用户认证与界面

1. 用户登录注册
   - 登录页面: /login
   - 注册页面: /register
   - 首页: /

2. 界面风格
   - 响应式设计，适配主流分辨率（优先桌面端）
   - 操作流畅，大规模故障树（>100节点）渲染性能良好
   - 界面风格简洁专业，符合工业软件审美
   - 突出信息层级与操作引导

六、技术栈

1. 前端框架
   - Vue 3 + Vite
   - Element Plus UI组件库
   - Vue Router路由管理
   - Pinia状态管理

2. 图形渲染
   - 推荐使用 D3.js、GoJS、AntV G6 或 React Flow 等成熟图可视化库
   - 当前使用Vue Flow或类似方案

3. 与后端通信
   - RESTful API
   - WebSocket（用于实时校验反馈）

4. 文件解析预览
   - PDF.js (PDF预览)
   - SheetJS (Excel预览)

七、API集成

1. 文档服务 (端口8091)
   - POST /api/v1/documents/upload - 上传文档
   - GET /api/v1/documents/{docId} - 获取文档信息
   - GET /api/v1/documents/{docId}/content - 获取文档内容

2. 向量存储服务 (端口8090)
   - POST /api/v1/vector/process - 处理文档向量
   - GET /api/v1/vector/search - 搜索相似向量

3. RAG生成服务 (端口8001)
   - POST /api/v1/rag/generate - 生成故障树
   - GET /api/v1/rag/tasks/{taskId} - 查询生成状态

4. 知识图谱服务 (端口8083)
   - GET /api/v1/kg/template - 获取模板

5. 规则校验服务 (端口8087)
   - POST /api/v1/validation/validate - 校验故障树

6. 故障树编辑服务 (端口8092)
   - CRUD操作故障树
