模块间数据流转图
================================================================================

┌─────────────────────────────────────────────────────────────────────────────────┐
│                              模块间数据流转                                       │
└─────────────────────────────────────────────────────────────────────────────────┘

  【文档上传 → 故障树生成】

  文档上传
     │
     ▼
  文档解析（DocumentService）
     │
     ▼
  向量存储（VectorStoreService）←── 可选：知识图谱更新
     │
     │ docId
     ▼
  RAG 获取文档内容
     │
     ▼
  多文档融合（FusionEngine）
     │
     ▼
  故障树生成（RAG）
     │
     ▼
  返回故障树


  【故障树生成 → 规则校验 → 故障树编辑 → 反馈学习 → 评估】

  故障树生成（RAG）
     │
     ▼
  规则校验（Validation）
     │
     ├─ 校验通过 ─▶ 故障树编辑（Editor）
     │                    │
     │                    ▼
     │               专家修改
     │                    │
     │                    ▼
     │               反馈学习（Feedback）
     │                    │
     │                    ▼
     │               评估服务（Evaluation）
     │
     └─ 校验失败 ─▶ 返回错误，重新生成
