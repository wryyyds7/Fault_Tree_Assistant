## 四、API调用

### 4.1 配置

文件位置: `src/api/index.js`

```javascript
const API_BASE_URL = '/api/v1'

const apiClient = axios.create({
  baseURL: API_BASE_URL,
  timeout: 30000,
  headers: {
    'Content-Type': 'application/json'
  }
})
```

**特性**:
- 自动携带 JWT Token (`Authorization: Bearer {token}`)
- 统一错误处理（401跳转登录，500显示错误等）
- 响应拦截器直接返回 `response.data`

### 4.2 API模块

| 模块 | 前缀 | 主要方法 |
|------|------|----------|
| authAPI | `/auth` | login, register |
| documentAPI | `/documents` | upload, getDocument, getDocumentList, deleteDocument |
| faultTreeAPI | `/fault-trees` | getAll, getById, create, update, delete, addNode, updateNode, deleteNode |
| validationAPI | `/validation` | validate |
| ragAPI | `/rag` | generate, getTaskStatus, getEvidence |
| knowledgeGraphAPI | `/kg` | queryTemplate, enrich, initialize |
| vectorAPI | `/vector` | search, searchWithEvidence |
| feedbackAPI | `/feedback` | create, getById, getByTreeId, getAll, processBatch |
| statsAPI | `/stats` | getDashboardStats |

### 4.3 使用示例

```javascript
import { faultTreeAPI, documentAPI } from '@/api'

// 创建故障树
const createTree = async (data) => {
  try {
    const result = await faultTreeAPI.create(data)
    return result
  } catch (error) {
    console.error('创建失败:', error)
  }
}

// 上传文档
const uploadDocument = (file, equipmentType) => {
  const formData = new FormData()
  formData.append('file', file)
  formData.append('sourceType', 'manual_upload')
  formData.append('equipmentType', equipmentType || '通用型')
  formData.append('persistToKnowledgeBase', 'true')
  return documentAPI.upload(formData)
}
```

## 五、Vite配置

文件位置: `vite.config.js`

```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { fileURLToPath, URL } from 'node:url'

export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    }
  },
  define: {
    global: 'globalThis'  // 解决sockjs-client的global问题
  },
  server: {
    port: 3001,
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true
      },
      '/ws': {
        target: 'http://localhost:8080',
        ws: true
      }
    }
  }
})
```

**重要**: 必须添加 `define: { global: 'globalThis' }` 否则 WebSocket 连接会报 `global is not defined`

**文件上传**:

```javascript
const handleUpload = async (file) => {
  const isValidType = ['application/pdf', 'text/plain',
    'application/vnd.openxmlformats-officedocument.wordprocessingml.document',
    'text/csv',
    'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'
  ].includes(file.raw.type)

  if (!isValidType) {
    ElMessage.error('只支持 PDF, TXT, DOCX, CSV, XLSX 文件')
    return false
  }

  const formData = new FormData()
  formData.append('file', file.raw)
  formData.append('sourceType', 'manual_upload')
  formData.append('equipmentType', equipmentType.value || '通用型')
  formData.append('persistToKnowledgeBase', 'true')

  await documentAPI.upload(formData)
  ElMessage.success('上传成功')
  fetchDocuments()
}
```

## 十、常见问题

### 10.1 图标导入错误

```
The requested module '/node_modules/.vite/deps/@element-plus_icons-vue.js'
does not provide an export named 'Keyboard'
```

**解决**: 检查图标名称是否正确，使用确实存在的图标。

### 10.2 global is not defined

**解决**: 在 `vite.config.js` 添加:

```javascript
define: {
  global: 'globalThis'
}
```

### 10.3 路由跳转失败

检查目标组件是否正确导入，路由参数是否匹配。
