# 故障树智能生成系统 - 前端开发流程文档

## 一、项目概述

### 1.1 项目背景
本项目是基于知识的工业设备故障树智能生成与辅助构建系统的前端部分，采用 Vue3 + Element Plus + ECharts 技术栈实现。

### 1.2 前端技术栈
- **框架**: Vue 3.4+
- **路由**: Vue Router 4.2+
- **UI组件库**: Element Plus 2.4+
- **图表可视化**: ECharts 5.4+ (用于故障树图形渲染)
- **HTTP客户端**: Axios 1.6+
- **WebSocket**: SockJS + STOMP
- **构建工具**: Vite 5.0+

## 二、后端API对接说明

### 2.1 API网关地址
- **开发环境**: `http://localhost:8080`
- **所有API请求都通过网关统一路由**

### 2.2 认证机制
- 登录接口: `POST /api/v1/auth/login`
- 请求头携带: `Authorization: Bearer <token>`

### 2.3 核心API列表

#### 认证服务 (auth-service)
| 接口 | 方法 | 说明 |
|-----|------|------|
| `/api/v1/auth/login` | POST | 用户登录 |
| `/api/v1/auth/register` | POST | 用户注册 |

#### 文档服务 (document-ingest-service)
| 接口 | 方法 | 说明 |
|-----|------|------|
| `/api/v1/documents/upload` | POST | 上传文档 |
| `/api/v1/documents/{docId}` | GET | 获取文档信息 |
| `/api/v1/documents/{docId}/content` | GET | 获取文档内容 |
| `/api/v1/documents` | GET | 获取文档列表 |

#### 故障树编辑服务 (fault-tree-editor-service)
| 接口 | 方法 | 说明 |
|-----|------|------|
| `/api/v1/fault-trees` | GET | 获取所有故障树 |
| `/api/v1/fault-trees/{treeId}` | GET | 获取指定故障树 |
| `/api/v1/fault-trees` | POST | 创建故障树 |
| `/api/v1/fault-trees/{treeId}` | PUT | 更新故障树 |
| `/api/v1/fault-trees/{treeId}` | DELETE | 删除故障树 |
| `/api/v1/fault-trees/{treeId}/nodes` | POST | 添加节点 |
| `/api/v1/fault-trees/{treeId}/nodes` | PUT | 更新节点 |
| `/api/v1/fault-trees/{treeId}/nodes/{eventId}` | DELETE | 删除节点 |
| `/api/v1/fault-trees/{treeId}/nodes/{eventId}/move` | PUT | 移动节点 |
| `/api/v1/fault-trees/{treeId}/positions` | PUT | 批量更新位置 |
| `/api/v1/fault-trees/{treeId}/nodes/{eventId}/confidence` | PUT | 更新置信度 |
| `/api/v1/fault-trees/{treeId}/nodes/{eventId}/verification` | PUT | 更新验证状态 |

#### 规则校验服务 (rule-validation-service)
| 接口 | 方法 | 说明 |
|-----|------|------|
| `/api/v1/validation/validate` | POST | 校验故障树逻辑 |

#### RAG生成服务 (rag-generation-service)
| 接口 | 方法 | 说明 |
|-----|------|------|
| `/api/v1/rag/generate` | POST | 触发生成 |
| `/api/v1/rag/tasks/{task_id}` | GET | 获取任务状态 |
| `/api/v1/rag/evidence/{paragraph_id}` | GET | 获取溯源证据 |
| `/api/v1/rag/evidence` | POST | 获取事件溯源列表 |

#### 知识图谱服务 (knowledge-graph-service)
| 接口 | 方法 | 说明 |
|-----|------|------|
| `/api/v1/kg/query-template` | POST | 查询模板 |
| `/api/v1/kg/enrich` | PUT | 丰富知识图谱 |

## 三、功能模块开发指南

### 3.1 故障树图形可视化 (FaultTreeChart.vue)

#### 功能实现
- ✅ 使用ECharts绘制故障树树状图
- ✅ 支持节点拖拽、缩放、展开/折叠
- ✅ 高亮显示置信度低的节点 (confidence < 0.8)
- ✅ 显示节点类型(顶/中/底)、逻辑门类型(AND/OR)
- ✅ 点击节点显示溯源信息
- ✅ 支持拖拽、缩放、平移

#### 核心数据结构
```javascript
// 故障树节点结构
{
  eventId: "evt_001",
  eventName: "电机过热停机",
  eventType: "TOP|INTERMEDIATE|BASIC",
  gateType: "AND|OR|XOR|NOT",
  confidence: 0.85,
  verificationStatus: "CONFIRMED|PENDING|REJECTED",
  aiGenerated: true,
  sourceDetail: {
    sourceId: "src_001",
    sourceType: "MANUAL|WORK_ORDER|AI_GENERATED",
    documentName: "电机维修手册.pdf",
    pageNumber: "23",
    paragraphId: "para_001",
    manualName: "GB/T 1234",
    workOrderNumber: "WO-2026-001"
  },
  position: { x: 100, y: 200 },
  children: []
}
```

#### ECharts配置要点
- 使用 `graph` 类型，`layout: 'tree'` 采用树形布局
- `orient: 'TB'` 从上到下布局
- `symbol` 自定义节点形状 (roundRect)
- `edgeSymbol: ['none', 'arrow']` 边的端点样式
- `roam: true` 支持拖拽缩放
- `draggable: true` 节点可拖拽

### 3.3 校验结果展示 (ValidationResult.vue)

#### 功能实现
- ✅ 展示故障树校验结果

- ✅ 支持定位到问题节点
- ✅ 支持应用建议修复

#### 校验错误类型
| errorType | 说明 | suggestion示例 |
|-----------|------|---------------|
| CIRCULAR_DEPENDENCY | 循环依赖 | 移除循环引用，重构故障树层级 |
| INVALID_BASIC_NODE | 底事件有子节点 | 移除子节点或修改事件类型 |
| INSUFFICIENT_INPUTS | 逻辑门输入不足 | 添加更多子节点满足最小输入数 |
| MISSING_EVENT_TYPE | 缺少事件类型 | 为事件分配事件类型 |

## 五、关键数据流

### 5.1 故障树生成流程
```
1. 用户上传文档 → Document.vue → POST /api/v1/documents/upload
2. 用户指定顶事件 → FaultTreeEdit.vue → POST /api/v1/rag/generate
3. 后台生成中 → 轮询 GET /api/v1/rag/tasks/{task_id}
4. 生成完成 → GET /api/v1/fault-trees/{treeId} 获取完整树
5. 前端渲染 → FaultTreeChart.vue 高亮低置信度节点
```

### 5.2 专家修正流程
```
1. 用户修改节点 → FaultTreeEdit.vue
2. PUT /api/v1/fault-trees/{treeId}/nodes 更新节点
3. POST /api/v1/validation/validate 触发校验
4. 展示校验结果 → ValidationResult.vue
5. 用户确认修改 → 置信度调整
6. PUT /api/v1/fault-trees/{treeId}/nodes/{eventId}/confidence
```

### 5.3 溯源查询流程
```
1. 用户点击节点 → FaultTreeChart.vue
2. 获取sourceDetail信息
3. SourceDetail.vue 展示详情
4. 可选: GET /api/v1/rag/evidence/{paragraph_id} 获取原始段落
```

## 六、状态管理

### 6.1 节点验证状态
```javascript
verificationStatus: {
  PENDING: "待确认",      // AI生成后初始状态
  CONFIRMED: "已确认",    // 专家确认无误
  REJECTED: "已驳回"       // 专家修正过
}
```

### 6.2 置信度阈值
```javascript
confidenceThreshold: {
  high: 0.9,    // 高置信度，正常显示
  medium: 0.7,  // 中置信度，黄色标记
  low: 0.5      // 低置信度，红色标记
}
```

### 6.3 事件类型
```javascript
eventType: {
  TOP: "顶事件",           // 故障现象/系统失效
  INTERMEDIATE: "中间事件", // 过渡原因
  BASIC: "底事件"          // 根本原因/最小割集
}
```

### 6.4 逻辑门类型
```javascript
gateType: {
  AND: "与门",   // 所有子事件同时发生
  OR: "或门",    // 任意子事件发生
  XOR: "异或门", // 有且仅有一个子事件发生
  NOT: "非门"   // 取反
}
```
