一、项目技术架构
================================================================================

┌─────────────────────────────────────────────────────────────────────────────────┐
│                              技术栈概览                                          │
└─────────────────────────────────────────────────────────────────────────────────┘

  前端技术：
  ├── Vue 3.4+ (渐进式JavaScript框架)
  ├── Vue Router 4.2+ (路由管理)
  ├── Element Plus 2.4+ (UI组件库)
  ├── ECharts 5.4+ (图表可视化)
  ├── Axios 1.6+ (HTTP客户端)
  ├── SockJS + STOMP (WebSocket通信)
  └── Vite 5.0+ (构建工具)

  后端技术（Java微服务）：
  ├── Spring Boot 3.2.x (应用框架)
  ├── Spring Cloud Alibaba 2023.0.3.4 (微服务生态)
  ├── Nacos (配置中心/服务发现)
  ├── Spring Cloud Gateway (API网关)
  ├── MyBatis 3.0.3 (ORM框架)
  ├── Drools (规则引擎)
  ├── Neo4j (知识图谱数据库)
  └── RabbitMQ (消息队列)

  Python服务：
  ├── FastAPI (HTTP API框架)
  ├── SockJS + STOMP (WebSocket通信)
  ├── BGE-M3 (向量模型)
  └── 百炼API/DashScope (LLM大模型)
