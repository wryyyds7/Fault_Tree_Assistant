一、常见问题与解决方案
================================================================================

┌─────────────────────────────────────────────────────────────────────────────────┐
│  1. RabbitMQ "channel not found" 错误                                           │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  问题描述：                                                                     │
│  - 消息队列显示 "channel not found" 或 "AMQP channel error"                    │
│  - 即使配置了持久化也会报错                                                      │
│                                                                                 │
│  根本原因：                                                                     │
│  - Spring Boot 3.x 默认不加载其他jar包中的@Bean配置                              │
│  - RabbitMQ配置类未被扫描到                                                     │
│                                                                                 │
│  解决方案：                                                                     │
│  - 在服务启动类添加 @ComponentScan 注解：                                        │
│                                                                                 │
│    @SpringBootApplication                                                        │
│    @ComponentScan(basePackages = {                                              │
│        "com.cxyaqcdm.fta.<service>",  // 服务自身包                             │
│        "com.cxyaqcdm.fta.common"      // common-core公共配置                    │
│    })                                                                             │
│    public class XxxServiceApplication { ... }                                    │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  2. Spring Boot 3.2 + MyBatis 兼容性问题                                        │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  问题描述：                                                                     │
│  - "Invalid value type for attribute 'factoryBeanObjectType': java.lang.String" │
│                                                                                 │
│  根本原因：                                                                     │
│  - MyBatis 2.3.x 与 Spring Boot 3.2.x 不兼容                                   │
│                                                                                 │
│  解决方案：                                                                     │
│  - 升级 MyBatis 版本到 3.0.3：                                                  │
│                                                                                 │
│    <dependency>                                                                  │
│        <groupId>org.mybatis.spring.boot</groupId>                               │
│        <artifactId>mybatis-spring-boot-starter</artifactId>                     │
│        <version>3.0.3</version>                                                │
│    </dependency>                                                                │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  3. Spring Cloud Alibaba 版本兼容性问题                                          │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  问题描述：                                                                     │
│  - 服务无法启动，配置中心连接失败                                                │
│  - 各种奇怪的 Bean 创建失败错误                                                  │
│                                                                                 │
│  解决方案：                                                                     │
│  - 使用兼容版本组合：                                                            │
│                                                                                 │
│    <dependency>                                                                  │
│        <groupId>com.alibaba.cloud</groupId>                                     │
│        <artifactId>spring-cloud-alibaba-dependencies</artifactId>               │
│        <version>2023.0.3.4</version>                                           │
│        <type>pom</type>                                                         │
│        <scope>import</scope>                                                    │
│    </dependency>                                                                │
│                                                                                 │
│    <dependency>                                                                 │
│        <groupId>com.alibaba.nacos</groupId>                                    │
│        <artifactId>nacos-client</artifactId>                                    │
│        <version>2.2.3</version>                                                │
│    </dependency>                                                                │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  4. Feign Client 使用 @PostMapping 报错                                          │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  问题描述：                                                                     │
│  - "PostMapping that is not used by contract Default"                           │
│                                                                                 │
│  根本原因：                                                                     │
│  - FeignClientConfig 使用了 Contract.Default，不支持 Spring MVC注解              │
│                                                                                 │
│  解决方案：                                                                     │
│  - 修改 FeignClientConfig 使用 SpringMvcContract：                              │
│                                                                                 │
│    @Bean                                                                        
│    public Contract springMvcContract() {                                        
│        return new SpringMvcContract();                                          
│    }                                                                            
│                                                                                 │
│  - 注意：修改后需要重新编译 common-core 模块                                      │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  5. RabbitMQ 消息反序列化失败                                                    │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  问题描述：                                                                     │
│  - "Cannot deserialize value of type java.lang.String from Object value"        │
│                                                                                 │
│  根本原因：                                                                     │
│  - 消息发送方发送的是对象，接收方用 String 接收                                  │
│                                                                                 │
│  解决方案：                                                                     │
│  - 确保 Listener 接收类型与发送方一致：                                          │
│                                                                                 │
│    // 发送方                                                                    
│    rabbitTemplate.convertAndSend(exchange, routingKey, mapObject);              
│                                                                                 │
│    // 接收方                                                                    
│    @RabbitListener(queues = "queue.name")                                        │
│    public void handleMessage(Map<String, Object> message) {                    
│        // 处理消息                                                              
│    }                                                                            
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  6. Vite "global is not defined" 错误                                            │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  问题描述：                                                                     │
│  - sockjs-client 等库使用 global 变量                                           │
│  - 浏览器环境没有 global，只有 globalThis                                       │
│                                                                                 │
│  解决方案：                                                                     │
│  - 在 vite.config.js 中添加 define 配置：                                       │
│                                                                                 │
│    export default defineConfig({                                                
│        plugins: [vue()],                                                        
│        define: {                                                                
│            global: 'globalThis'                                                 
│        },                                                                       
│        server: {                                                                
│            port: 3001,                                                          
│            proxy: {                                                             │
│                '/api': {                                                        │
│                    target: 'http://localhost:8080',                              │
│                    changeOrigin: true                                         
│                }                                                                │
│            }                                                                    │
│        }                                                                       
│    })                                                                           
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  7. Element Plus 图标组件导入错误                                                │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  问题描述：                                                                     │
│  - "The requested module does not provide an export named 'Keyboard'"          │
│                                                                                 │
│  根本原因：                                                                     │
│  - Element Plus 图标名称可能与实际导出不符                                       │
│  - 部分图标在特定版本中已被移除或重命名                                          │
│                                                                                 │
│  解决方案：                                                                     │
│  - 检查 Element Plus 图标库实际提供的图标名称                                    │
│  - 使用确实存在的图标替代：                                                      │
│                                                                                 │
│    import { Edit, Plus, Check, ... } from '@element-plus/icons-vue'             
│                                                                                 │
│  - 避免使用不存在的图标（如 Keyboard）                                           │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  8. Drools 规则引擎编译错误                                                      │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  问题描述：                                                                     │
│  - "could not resolve class: HashSet<String>"                                   │
│  - "unable to resolve method using strict-mode: addError"                      │
│                                                                                 │
│  解决方案：                                                                     │
│  - 将 dialect="mvel" 改为 dialect="java"                                        │
│  - 移除规则中的泛型声明（如 HashSet<String> 改为 HashSet）                       │
│                                                                                 │
│    rule "Check Cycle"                                                          
│        dialect "java"                                                          
│        when                                                                     
│            // 使用原生类型而非泛型                                                │
│        then                                                                     
│    end                                                                         
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  9. Feign 接口参数不匹配                                                         │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  问题描述：                                                                     │
│  - "无法将接口中的方法应用到给定类型"                                            │
│  - 实际参数列表和形式参数列表长度不同                                            │
│                                                                                 │
│  根本原因：                                                                     │
│  - Controller、Service、FeignClient 三处方法签名不一致                          │
│                                                                                 │
│  解决方案：                                                                     │
│  - 确保所有层级的方法签名完全一致：                                              │
│                                                                                 │
│    // Controller                                                               
│    @PostMapping("/documents/{docId}/paragraphs")                               
│    public ResponseEntity<List<ParagraphMetadata>> createParagraphMetadata(     
│        @PathVariable String docId,                                             
│        @RequestBody List<Map<String, Object>> paragraphs,                     
│        @RequestParam(required = false) String userId) { ... }                 
│                                                                                 │
│    // Service                                                                  
│    List<ParagraphMetadata> createParagraphMetadata(                           
│        String docId,                                                           
│        List<Map<String, Object>> paragraphs,                                   
│        String userId);                                                         
│                                                                                 │
│    // Feign Client                                                             
│    @PostMapping("/documents/{docId}/paragraphs")                               
│    List<ParagraphMetadata> createParagraphMetadata(                           
│        @PathVariable("docId") String docId,                                     
│        @RequestBody List<Map<String, Object>> paragraphs,                     
│        @RequestParam(value = "userId", required = false) String userId);       
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  10. 端口冲突问题                                                                │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  问题描述：                                                                     │
│  - "Port 8080/8081/8082 was already in use"                                     │
│                                                                                 │
│  解决方案：                                                                     │
│  - 查找占用端口的进程：                                                         │
│                                                                                 │
│    netstat -ano | findstr :8080                                                │
│                                                                                 │
│  - 结束进程：                                                                   │
│                                                                                 │
│    taskkill /PID <进程ID> /F                                                    │
│                                                                                 │
│  - 或修改服务端口：                                                              │
│                                                                                 │
│    # application.yml                                                           
│    server:                                                                      
│      port: 8092  # 改为其他端口                                                 │
│                                                                                 │

三、数据库配置
================================================================================

  Oracle 连接信息：
  - URL: jdbc:oracle:thin:@localhost:1521:XEPDB1
  - 用户: fta_user / fta_vector_user
  - 驱动: oracle.jdbc.OracleDriver

  主要表：
  - auth_db.users - 用户表
  - fta_db.fault_trees - 故障树表
  - fta_vector_db.document_metadata - 文档元数据
  - fta_vector_db.paragraph_metadata - 段落元数据
  - fta_vector_db.vector_store - 向量存储
  - feedback_db.feedback - 反馈表

四、前端开发注意事项
================================================================================

┌─────────────────────────────────────────────────────────────────────────────────┐
│  1. API调用                                                                      │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  - 所有请求通过 /api/v1 前缀                                                    │
│  - 自动携带 JWT Token                                                           │
│  - 错误处理已统一封装                                                           │
│                                                                                 │
│  使用示例：                                                                     │
│  import { faultTreeAPI } from '@/api'                                         
│                                                                                 
│  const createTree = async (data) => {                                         
│      const result = await faultTreeAPI.create(data);                          
│      return result;                                                            
│  }                                                                              
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  2. 文件上传                                                                    │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  - 使用 FormData 封装文件                                                       │
│  - 注意设置 Content-Type: multipart/form-data                                  │
│  - 文档上传时需要 sourceType、equipmentType 等参数                              │
│                                                                                 │
│  示例：                                                                         │
│  const uploadDocument = (file, equipmentType) => {                            
│      const formData = new FormData();                                         
│      formData.append('file', file);                                            
│      formData.append('sourceType', 'manual_upload');                          
│      formData.append('equipmentType', equipmentType || '通用型');              
│      formData.append('persistToKnowledgeBase', 'true');                       
│      return documentAPI.upload(formData);                                     
│  }                                                                              
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  3. 故障树编辑页面路由                                                           │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  - 列表页: /fault-tree                                                          │
│  - 编辑页: /fault-tree/edit/:treeId 或 /fault-tree/edit/new                    │
│  - 编辑页需要从路由获取 treeId 参数                                             │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

五、后端开发注意事项
================================================================================

┌─────────────────────────────────────────────────────────────────────────────────┐
│  1. 服务间调用                                                                   │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  - 使用 Feign Client 进行服务间调用                                             │
│  - 引入 common-core 获取公共配置                                                │

│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  2. 消息队列使用                                                                │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  - 使用 PersistentMessageSender 发送持久化消息                                 │
│  - 消费者使用 @RabbitListener 注解                                              │
│  - 注意消息类型匹配                                                             │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────┐
│  3. 用户上下文传递                                                              │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  - 使用 UserContext 从 ThreadLocal 获取用户信息                                 │
│  - Feign调用时自动传递用户上下文                                                │
│  - 无需手动处理                                                                │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
